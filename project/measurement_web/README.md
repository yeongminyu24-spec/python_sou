# 측정 데이터 검토 실습

## 실행 (Windows PowerShell)

```powershell
cd C:\Users\Hi\python_sou\project\measurement_web
python -m pip install -r requirements.txt
python app.py
```

브라우저에서 http://127.0.0.1:5000 을 열고 .xlsx 파일을 선택한 뒤 **분석하기**를 누릅니다.
다른 Flask 실습이 5000번 포트를 사용 중이면 먼저 종료하세요. 서버 종료는 Ctrl+C입니다.
업로드 파일은 메모리에서 읽으며 디스크에 저장하지 않습니다. 최대 크기는 20MB입니다.
이 서버는 로컬 학습용이며 debug 모드를 사용합니다.

## 엑셀 양식

- 모든 시트(숨김 시트 포함)를 읽으며 시트 이름을 도면 페이지로 사용합니다.
- 13행은 제목, 14행부터 데이터입니다.
- C: 항목 번호, D: 위치, E: 측정 종류, F: 기준 치수
- G: 상측 공차의 **크기**, H: 하측 공차의 **크기** (모두 0 이상)
- T: Notes
- SPL 열은 13행의 `Spl 1`, `Spl 2` 등의 제목으로 찾습니다. 대소문자는 구분하지 않습니다.
- C~F가 모두 비어 있는 행은 제외합니다. 통계/설명 행에 C~F 값이 있으면 항목으로 읽힐 수 있습니다.

## 판정과 평균

하한 = F − H, 상한 = F + G. 경계값도 OK이며 숫자 0은 유효한 측정값입니다.

| 상황 | 요약 분류 | 추가 표시 |
|---|---|---|
| 모든 SPL이 측정되었고 범위 안 | OK | 각 SPL의 OK |
| 유효한 규격에서 하나라도 범위 밖 | NG | 미측정/값 오류가 함께 있으면 같이 표시 |
| 정상 규격이고 SPL이 모두 빈칸 | 미측정 | 미측정 |
| 일부 SPL이 빈칸, 범위 밖 값은 없음 | 확인 필요 | 일부 미측정 |
| SPL에 숫자가 아닌 값 | 확인 필요 (범위 밖 값도 있으면 NG) | 값 오류 |
| 규격 누락/문자/음수 공차 | 확인 필요 | 규격 오류 |
| SPL 머리글 없음 | 확인 필요 | SPL 열 없음 및 시트 경고 |

평균은 **각 항목 안의 유효한 SPL 값만** 직접 계산합니다. 규격 밖 숫자도 평균에는 포함합니다.
서로 다른 항목이나 시트의 측정값을 합쳐 평균을 내지 않습니다.
미측정/값 오류가 있으면 평균은 부분 데이터에 대한 값이므로 유효 값 개수를 함께 표시합니다.
Notes는 그대로 표시하며 판정에 영향을 주지 않습니다. 기존 통계 수식은 사용하지 않습니다.
SPL이나 규격 칸의 수식은 직접 계산하지 않으며 값 오류/규격 오류로 표시합니다.
숫자는 소수점 표기나 숫자형 문자열을 허용하며 단위가 붙은 문자열은 오류입니다.

상단 요약은 전체 파일 기준입니다. 페이지 필터는 표의 표시 행만 변경합니다.

## 코드 읽는 순서

평균은 소수점 둘째 자리까지 반올림(ROUND_HALF_UP)해서 표시합니다. 계산과 비교는 반올림 전 값을 사용합니다.
화면의 평균 편차 기준(기본 10%)보다 `|SPL − 항목 평균|`이 `|항목 평균| × 기준 / 100`을 초과하면
해당 SPL에 **값 검토 필요**를 표시합니다. 규격 판정과 요약 분류는 변경하지 않습니다.
유효 값이 2개 이상일 때 적용하고, 평균이 0이면 0이 아닌 SPL을 표시합니다.
부분 측정이면 유효한 값만으로 비교합니다. 이 기준은 검토 보조용이며 통계적 이상치를 확정하지 않습니다.
기준을 변경한 뒤에는 파일을 다시 선택하고 분석하세요.

1. `index()`가 파일 업로드 요청을 받습니다.
2. `analyze_workbook()`이 시트와 행을 읽고 SPL/규격을 분석합니다.
3. `number()`가 빈칸과 0을 구분하고 숫자를 검증합니다.
4. `index.html`이 결과를 출력하고 JavaScript가 페이지 필터를 적용합니다.
